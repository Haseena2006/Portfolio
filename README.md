# P. Haseena Fathim – Portfolio

Static site (HTML5, CSS3, vanilla JS). Open `index.html` or deploy the folder to GitHub Pages / Netlify / Vercel.

## Edit content
- `js/data.js` – skills, projects, internships, typing texts, email
- `assets/profile.jpg` – add your photo (shows "HF" initials until then)
- `assets/Haseena_Fathim_P_Resume.pdf` – resume download
- Project GitHub buttons point to your profile; replace `repo` in `js/data.js` with exact repo URLs.

## Notes
- Contact form validates input, then opens the visitor's email app (no backend needed). For direct delivery, connect Formspree/EmailJS.

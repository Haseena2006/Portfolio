## Features

- Responsive design for desktop, tablet and mobile
- Dark and light mode toggle (remembers your choice)
- Animated typing text in the hero section
- Smooth scrolling navigation with active link highlight
- Scroll reveal animations and animated skill badges
- Interactive project cards with expandable details
- Internship timeline, certifications and achievements sections
- Contact form with real-time validation
- Downloadable resume
- Back-to-top button
- SEO-friendly meta tags and accessible markup (skip link, ARIA labels, keyboard focus, reduced-motion support)

## Run Locally

```bash
git clone https://github.com/Haseena2006/portfolio.git
cd portfolio
```

Then open `index.html` in your browser. No build step or installation needed.

## Customize

- **Content:** edit `js/data.js` to update skills, projects, internships and project GitHub links.
- **Photo:** replace `assets/profile.jpg`.
- **Resume:** replace `assets/Haseena_Fathim_P_Resume.pdf`.
- **Colors:** change the CSS variables at the top of `css/style.css`.

## Deploy on GitHub Pages

1. Push the project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose the `main` branch and `/ (root)` folder, then click **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
